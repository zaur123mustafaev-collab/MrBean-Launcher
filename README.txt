MrBean Launcher 2.1 + MrBean Visuals 2.1.0 (Minecraft 1.21.11, Fabric)
=====================================================================

ЗАПУСК
  Ярлык «MrBean Launcher» на рабочем столе или D:\MrBeanLauncher\MrBeanLauncher.exe.
  Всё хранится на D:\MrBeanLauncher (игра, Java, моды, настройки).
  Кнопка «ИГРАТЬ» сама скачает Java, Minecraft 1.21.11, Fabric, Fabric API и MrBean Visuals.

В ИГРЕ
  Правый Shift  — меню MrBean Visuals (10 категорий, поиск, темы)
  Кнопка «HUD» в меню — редактор HUD (перетаскивание, привязка, пресеты)
  При первом запуске откроется мастер настройки из 6 шагов.

ВХОД ЧЕРЕЗ MICROSOFT (лицензия)
  Основной способ — официальный вход Microsoft в вашем браузере (OAuth 2.0 + PKCE).
  Пароль лаунчер не видит и не хранит. Токены шифруются Windows (DPAPI) в accounts.json.
  Лицензию проверяет сам Microsoft/Mojang — лаунчер ничего не обходит и не имитирует.

  Как войти: Аккаунты → «Войти через Microsoft». Лаунчер займёт локальный порт
  (http://localhost:48120), покажет ссылку и откроет браузер. Входите в свой аккаунт там,
  после чего браузер вернёт код лаунчеру и аккаунт появится в списке.
  Если браузер не смог вернуть ответ (антивирус, прокси, занят порт, вы закрыли окно),
  лаунчер сам предложит запасной способ: «Войти по коду» → код на microsoft.com/link.
  Этот же способ можно выбрать сразу кнопкой «Войти по коду».

  Client ID вводит один раз автор лаунчера, игрокам его вносить не нужно.
  Пока его нет, лаунчер показывает понятную подсказку (не ошибку) и даёт играть офлайн-ником.
  Как зарегистрировать своё приложение:
   1. https://portal.azure.com → «Регистрация приложений» → «Новая регистрация»,
      тип поддержки: «Только личные учётные записи Microsoft» (иначе AADSTS50020).
   2. «Проверка подлинности» → «Добавить перенаправление» → Веб, адрес:
      http://localhost:48120   (без слэшей на конце; лаунчер покажет точный адрес в подсказке).
   3. «Проверка подлинности» → «Разрешить потоки общедоступных клиентов» = Да.
      Секрет клиента НЕ создавать и нигде не вписывать.
   4. Скопируйте «Идентификатор приложения (клиента)» → лаунчер: Аккаунты →
      «Настройка входа (Client ID)». Он сохраняется в launcher.json один раз.
   5. Отправьте этот ID на одобрение Mojang: https://aka.ms/mce-reviewappid
      (без одобрения вход отклонит Minecraft, а не лаунчер).
  Все ошибки Microsoft лаунчер объясняет по-русски в отдельном окне, с шагами исправления
  и ссылкой; в лог игры токены не попадают.
  Без Client ID можно играть с офлайн-ником (одиночная игра и серверы без лицензии).

ГЛАВНОЕ МЕНЮ И АККАУНТЫ
  Своё анимированное главное меню, стильные кнопки в мультиплеере и настройках.
  Карточка справа вверху / кнопка «Аккаунт» в мультиплеере — смена аккаунта прямо из игры:
  игра закроется и лаунчер сам запустит её с выбранным аккаунтом.
  Выключить: меню MrBean → Визуалы → «Главное меню MrBean».

AUTO DUEL (только ReallyWorld)
  Утилиты → Auto Duel. Наведитесь на игрока и нажмите G — уйдёт /duel ник (можно ставку).
  По желанию: принимать вызовы (по кнопке из чата сервера) и реванш после боя.

ОПТИМИЗАЦИЯ
  Лаунчер сам ставит и обновляет Sodium, Lithium, FerriteCore, ImmediatelyFast, EntityCulling,
  More Culling, Dynamic FPS, Sodium Extra, Reese's Sodium Options (+ Cloth Config).
  Выключить: Настройки → «Моды оптимизации» (удалит только то, что поставил лаунчер).
  Ещё вариант — в игре: меню → Производительность → «Моды оптимизации».
  Sodium, Lithium, FerriteCore, ImmediatelyFast, EntityCulling и др. ставятся только с Modrinth,
  только после вашего подтверждения, с проверкой SHA-512 и резервной копией (можно откатить).

СБОРКА И РЕЗЕРВНЫЕ КОПИИ
  Исходники: D:\MrBeanLauncher\src  (MrBeanLauncher.csproj, .NET Framework 4.8, WinForms).
  Сборка:      cd /d D:\MrBeanLauncher\src  &&  dotnet build -c Release
  Готовый файл: D:\MrBeanLauncher\src\bin\Release\net48\MrBeanLauncher.exe
                (он же копируется в D:\MrBeanLauncher\MrBeanLauncher.exe)
  Оригинал не удалён: D:\MrBeanLauncher\backup\MrBeanLauncher-2.1-original.exe,
  прежний рабочий файл: D:\MrBeanLauncher\MrBeanLauncher.exe.bak,
  прежнее состояние настроек: D:\MrBeanLauncher\launcher.json.bak.
